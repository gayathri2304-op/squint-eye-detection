# squint-eye-detection
A computer vision and deep learning-based system for detecting squint eyes from facial images. The system detects the face and eye regions, extracts facial landmarks, processes the eye area, and classifies whether the eye shows signs of squint or normal alignment.
# Squint Eye Detection

## Project Status
In Development

## About the Project

Squint Eye Detection is a computer vision and deep learning-based
project designed to identify whether a person's eye shows signs
of squint or normal alignment from a facial image.

## Working Process

1. User uploads a facial image.
2. The system detects the face.
3. The eye region is identified and cropped.
4. Facial landmarks are extracted from the eye region.
5. The processed eye features are given to the classification model.
6. The system predicts whether the eye is squint or normal.
